# Source and dataset registry

Updated 2026-10-28. Status: **Partially implemented**. All 43 supplied candidates
are tracked below. URLs are **supplied candidates**, not verified official URLs
unless a review explicitly says so. A reachable page is not a security, license,
maintenance or compatibility approval. No resource was downloaded or integrated
as part of this enterprise adoption milestone; existing optional dependencies
and experiments remain subject to audit.

`Pending` means unverified, not permission granted or a missing value that may
be guessed. Unreviewed entries have no verified owner, size, geographic coverage,
update schedule, quality assessment or installation recommendation. Before use,
record these plus exact version/revision, license evidence, model/data rights,
access limits, dependency compatibility, privacy risks and measured hardware
cost. Dataset use for evaluation, training and redistribution needs separate
rights assessment. Proprietary inputs require authorization.

## Initial official-source checks (2026-10-28)

- **Docling:** its owner repository was reachable and documents structured
  parsing, an MIT code license and separate model licenses. Candidate for a
  bounded optional layout-parser trial; no package, weights or performance
  validated here. [Owner README](https://raw.githubusercontent.com/docling-project/docling/main/README.md).
- **PaddleOCR:** its owner repository was reachable, displays an Apache-2.0
  code license and links local deployment documentation. Candidate only after
  comparing existing Windows OCR on the selected documents. Model rights,
  selected backend wheels and memory costs remain unverified.
  [Owner repository](https://github.com/PaddlePaddle/PaddleOCR).
- **DocILE:** its owner repository distinguishes the Python benchmark tooling
  from dataset download, which requires a secret token. The MIT code badge
  does not establish dataset commercial rights. Do not acquire or use the corpus
  until its data agreement is reviewed. [Owner instructions](https://raw.githubusercontent.com/rossumai/docile/main/README.md).
- **LangGraph:** official README documents stateful execution and human review.
  Current Sweep tasks already provide permissions, records and manual recovery.
  Defer framework adoption until a concrete durability gap justifies migration;
  this is an architectural decision, not a benchmark comparison.
  [Owner README](https://raw.githubusercontent.com/langchain-ai/langgraph/main/README.md).

No release-date/maintenance-frequency assertion is made from repository
popularity. No tested install command or dependency pin exists for these four
enterprise candidates yet. The resource-specific official installation links
above are research references, not instructions to change the working environment.

## Review queue and adoption gate

1. Establish the existing local PDF/page-text and Windows OCR fixture baseline.
   Preserve input hashes, extraction method and actual missing regions.
2. Assess Docling/PaddleOCR only if those fixtures expose needed layout/OCR gaps;
   verify selected software and model licenses, offline behavior, bounded resource
   use, Python/Windows packaging and output provenance before integration.
3. Verify relevant invoice/packing-list evaluation data and use only permitted
   samples. Synthetic fixtures are clearly labeled and never presented as real
   customer accuracy. Resolve the supplied WildReceipt URL before any use.
4. Verify official trade sources, rate/access/redistribution terms and geography
   when research is added. Historical statistics are not live shipment records.
5. Review the remaining security/evaluation resources for the corresponding
   phase; Vision/Evidence datasets and frameworks remain optional and deferred.

Each adoption must add: owner; exact source/revision and access date; license
and permitted uses; size/coverage/geography/quality/update frequency; install
and transitive dependencies; privacy/security assessment; sample/data hashes;
measured results and CPU/RAM/storage/cost; acceptance decision and reason.
Do not replace pending entries with inferred benchmark scores or legal clearance.
