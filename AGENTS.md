# Sweep Agent Guidelines

This project uses AI agents to help with development. Follow these guidelines:

- Keep commits focused and descriptive
- Test changes before committing
- Follow existing code conventions
- Read `docs/DEVELOPMENT_STATE.md` before continuing Sweep work; update its remaining tasks and validation evidence after each milestone.
- Before every new Sweep task, read both `docs/directives/SWEEP_ENTERPRISE_MASTER.md` and `docs/directives/SWEEP_IMPLEMENTATION_RESOURCES.md` in full, then `docs/DEVELOPMENT_STATE.md`. Follow their audit-first, TradeOps-first plan and record actual status/evidence; the adoption and precedence rules are in `docs/directives/README.md`.
